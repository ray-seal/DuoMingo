# 🦩 DuoMingo

**French for the thoroughly fed up.**

A cheerful, slightly irreverent French-learning PWA for the phrases your textbook conveniently left out. Learn the difference between literal translations and what people actually mean, practise pronunciation, collect phrases, earn XP, and take the patience exam.

## First version

- Nine bite-sized lesson paths, from polite to gloriously fed up
- Natural meaning, literal translation, and pronunciation guides
- Phrasebook for learned expressions
- Multiple-choice quiz with XP, now covering the expanded vocabulary
- Progress saved locally in the browser
- Responsive mobile-first layout and installable web-app manifest

## Run locally

```bash
npm install
npm run dev
```

Build with `npm run build`.

This is a humour-led language-learning project. Rude phrases are labelled as such; silly invented insults are not presented as established French idioms. Check context before deploying vocabulary in the wild.
